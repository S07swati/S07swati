# 🌍 TripTailor – Travel Accommodation Listing Platform

**TripTailor** is a full-stack web application built as part of my final-year Computer Science project. It allows users to browse and manage travel property listings in a clean, responsive interface.


## 🔗 Live Demo
👉 [TripTailor is live here](https://triptailor-og1j.onrender.com/listings)

---

## 🛠 Tech Stack

### Frontend
- HTML5, CSS3, Bootstrap – for responsive and aesthetic UI
- JavaScript, EJS – for dynamic content rendering

### Backend
- Node.js + Express.js – lightweight and efficient server-side logic

### Database
-MongoDB with Mongoose – NoSQL data storage with schema-based modeling

### Authentication
- Passport.js – local strategy for user login/signup
- Express-session – session management for logged-in users

### Deployment
- Render – cloud platform to deploy and host the app

---

## ✨ Features

- 🌐 Public listing browsing with location, price, and title
- 🔐 Secure user authentication for managing listings
- 📝 CRUD operations (Create, Read, Update, Delete) for property management
- 💬 Flash messages for success/error feedback
- 📱 Fully responsive across devices
